# Contributing

Thanks for considering a contribution.

1. Keep changes local-first and Python-standard-library oriented where practical.
2. Preserve existing workflow node behavior unless the change is intentional.
3. Run `python -m py_compile app.py` and `python -m unittest discover -s tests`.
4. Do not commit generated images, logs, model weights, caches, or local path
   configuration.
5. Describe the ComfyUI version and model workflow used to test your change.
